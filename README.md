# omarsalahc.github.io

Personal site, built with Jekyll and served by GitHub Pages.

## Editing

- **About text** — `index.md`
- **Name, role, links, location** — `_config.yml` (the `author:` block)
- **Headshot** — drop a square image at `assets/images/profile.jpg`
- **Colors and type** — `assets/css/style.css` (CSS variables at the top)

## Running locally (optional)

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000. Pushing to `main` publishes automatically.
